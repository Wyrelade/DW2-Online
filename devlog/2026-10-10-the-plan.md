# The plan

*2026-10-10*

The [decompilation](https://github.com/Wyrelade/Digimon-World-2-Decomp) turned all 1088 functions
of Digimon World 2 into C. The [PC port](https://github.com/Wyrelade/DW2-PC) runs that C on
Windows and Linux. DW2 Online uses the same code and adds a server.

The idea: the server runs the original game rules, and the client shows the result. To make that
possible, the game logic is being split from the drawing.

Planned for the online game (decided on 2026-10-08, can still change):

- Digital City as a shared hub with chat and a market.
- Domains as solo runs, started from domain items.
- Item drops with random extra effects.
- Digimon quality: Normal, Fine, Rare or Shiny.
- Guard Teams as factions.
- Player versus player (PvP) battles.
- Free, no shop.
