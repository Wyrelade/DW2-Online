# The plan for DW2 Online

*2026-10-10*

The [Digimon World 2 decompilation](https://github.com/Wyrelade/Digimon-World-2-Decomp) is done:
all 1088 functions of the game are C that rebuilds the retail disc byte for byte. The
[PC port](https://github.com/Wyrelade/DW2-PC) compiles that C for Windows and Linux. DW2 Online
is the next step: the same game code, with a server and other players. The design was settled
on 2026-10-08.

## Why the original code matters

Most fan online projects rebuild a game from scratch and guess the rules. Here the rules are the
original code. The server runs the game's own battle and domain code without a window, and the
client plays back what the server decided. Battles, damage, digivolution and DNA stay exactly as
they were in 2000.

Before any of that could work, the game logic had to be split from the picture. On the
PlayStation, one random number stream fed both the battle rules and the visual effects, so a
battle's result depended on how many frames the effects took. That stream is now split: effects
draw from their own stream, and the rules draw from a stream only the server can predict.
Replays of retail battles still match the PlayStation step by step.

## What the online game is

- Digital City is the hub: other tamers, chat, the market.
- Domains are your own runs, started from domain items with a level and extra rules.
- Gear and Digi-Beetle parts drop with random extra effects.
- Each recruited Digimon has a quality: Normal, Fine, Rare or Shiny.
- Guard Teams are factions for chat, a ladder and seasons, with no power.
- PvP on the original battle rules.
- Free, with no shop.
